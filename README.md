# 📖 Sobre o Projeto

O **DevRoad** é uma plataforma Open Source criada para organizar e facilitar o aprendizado de programação.

A proposta é transformar conteúdos gratuitos espalhados pela internet em trilhas de aprendizado estruturadas, reunindo vídeos do YouTube, documentações oficiais, exercícios e projetos práticos em um único ambiente.

A plataforma organiza o aprendizado por tecnologias e níveis de conhecimento, permitindo que o usuário acompanhe uma sequência de aulas e desenvolva suas habilidades de forma progressiva.

O objetivo é tornar o aprendizado de programação mais acessível, organizado e prático.

# 🎓 Sistema de Aulas Dinâmicas

Uma das principais características do DevRoad é o sistema de aulas dinâmicas.

Em vez de criar uma página individual para cada aula, a plataforma utiliza rotas dinâmicas que identificam a tecnologia, o módulo e a aula solicitada.

Exemplo:

```text
/aulas/html-css/01/01
/aulas/javascript/01/01
/aulas/python/01/01
/aulas/typescript/01/01
/aulas/angular/01/01
/aulas/nextjs/01/01
```

A página consulta o PostgreSQL por meio do Prisma ORM e recupera as informações correspondentes à aula.

## Recursos disponíveis nas páginas de aulas

- Título e descrição.
- Vídeo incorporado do YouTube.
- Identificação do canal.
- Documentação complementar.
- Exercícios.
- Projetos práticos.
- Tempo estimado de estudo.
- Lista de aulas do módulo.
- Navegação entre aulas.

## Integração com YouTube

Os vídeos são cadastrados individualmente no banco de dados.

A aplicação extrai automaticamente o identificador do vídeo e transforma o endereço em um player incorporado.

Quando uma aula não possui vídeo cadastrado, a página apresenta uma mensagem de indisponibilidade, sem comprometer o restante do conteúdo.

## Documentação

Cada aula pode possuir um link de documentação complementar, priorizando fontes oficiais das tecnologias estudadas.

## Navegação

- Navegação para a aula anterior e próxima.
- Navegação restrita às aulas do módulo atual.
- Retorno ao roadmap ao chegar à última aula do módulo.
- Sidebar com a relação de aulas disponíveis.

# 🔐 Sistema de Autenticação

O DevRoad utiliza Auth.js (NextAuth.js v5) para gerenciar a autenticação dos usuários.

Funcionalidades implementadas:

- Cadastro de usuários.
- Login.
- Gerenciamento de sessão.
- Proteção das páginas de aulas.
- Redirecionamento para login quando o usuário não está autenticado.

Exemplo da verificação de sessão no servidor:

```jsx
import { auth } from "@/auth";
import { redirect } from "next/navigation";

const session = await auth();

if (!session?.user) {
  redirect("/login");
}
```

# 🗄️ Banco de Dados

O banco de dados utiliza PostgreSQL, com hospedagem em Neon e integração por meio do Prisma ORM.

## Principais modelos

| Modelo | Responsabilidade |
|---|---|
| User | Dados dos usuários |
| Tecnologias | Tecnologias disponíveis |

## Relacionamentos

```text
Tecnologia
    |
    └── Módulos
          |
          └── Aulas

    |
    ├── Progresso
    |
    └── Favoritos
```

A estrutura permite relacionar tecnologias, módulos, aulas e usuários, facilitando a expansão da plataforma.

# ⚙️ Configuração do Ambiente

## Pré-requisitos

- Node.js 22 ou superior.
- Git.
- PostgreSQL local ou uma instância Neon.

## Instalação

```bash
git clone https://github.com/MeirelesDiogo/DevRoad.git

cd DevRoad

npm install
```

## Variáveis de ambiente

Crie um arquivo `.env` na raiz do projeto:

```env
DATABASE_URL="sua_connection_string_do_postgresql"
AUTH_SECRET="sua_chave_secreta"
```

## Prisma

Gere o Prisma Client:

```bash
npx prisma generate
```

Para visualizar os dados:

```bash
npx prisma studio
```

**Observação:** a configuração do Prisma ORM v7 utiliza `prisma.config.ts` e Driver Adapter. Consulte os arquivos de configuração do projeto antes de executar comandos de migração ou alterar o banco de dados.

## Executando o projeto

```bash
npm run dev
```

Acesse:

```text
http://localhost:3000
```
